# Support

For help with PodBridge, open an issue in this repository:

<https://github.com/dbalantaev/PodBridge-Store/issues>

Please include:

- PodBridge version;
- iOS/iPadOS version;
- iPod model and restore platform, if known;
- the step where the problem occurred;
- any non-sensitive error text.

Never upload music, private file paths, Apple account credentials, or private
diagnostic reports.
