PODBRIDGE

Support

PodBridge moves authorized music files from Files on iPhone, iPad, or Mac to supported click-wheel iPods and provides library tools for artwork, metadata, playlists, and duplicates.

Get help

Open a support issue on GitHub

Please include the PodBridge version, iOS/iPadOS or macOS version, iPod model and restore platform, the step where the problem occurred, and non-sensitive error text.

Before contacting support

  • Make sure the iPod appears in Files or is mounted on Mac.
  • Use a data-capable cable or adapter.
  • Choose the matching iPod profile.
  • Start with one authorized music file and keep a recoverable backup.

Never upload music, private file paths, Apple account credentials, or private diagnostic reports. PodBridge does not bypass DRM and is not affiliated with Apple.
